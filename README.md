
# Principio de Menor Sorpresa (POLA)

## Introducción

En este proyecto presento el Principio de Menor Sorpresa (POLA), que consiste en diseñar programas que se comporten de la manera que el usuario espera.

Para demostrarlo, desarrollé dos versiones de un pequeño juego RPG en Java. La primera contiene algunas confusiones en el menú y la segunda presenta mejoras para que las opciones sean más claras y fáciles de utilizar.

## Documentos del proyecto

### POLA

Es la versión original, en la que se presentan problemas de claridad en las opciones del menú.

- `Main.java`: contiene el menú principal y las acciones del juego.
- `Personaje.java`: contiene los atributos y métodos de los personajes.

### ProyectoMejorado

Es la versión corregida, en la que las opciones son más claras y las acciones corresponden a lo que el usuario espera.

- `Main.java`: contiene el menú mejorado y las opciones del juego.
- `Personaje.java`: contiene los atributos, el ataque, la defensa y la información de los personajes.

## Cómo ejecutar los proyectos

1. Descargar o clonar el repositorio desde GitHub.
2. Abrir Apache NetBeans.
3. Seleccionar **File > Open Project**.
4. Buscar la carpeta donde se descargó el repositorio.
5. Seleccionar el proyecto `POLA` y hacer clic en **Open Project**.
6. Ejecutar el proyecto con **Run Project** o presionando `F6`.
7. Para probar la versión mejorada, repetir el proceso y abrir el proyecto `ProyectoMejorado`.

## Conclusión

Con este proyecto pude comparar dos versiones del mismo juego y observar cómo la claridad de las opciones influye en la experiencia del usuario.

La versión mejorada busca que cada opción sea fácil de entender y que el programa haga lo que el usuario espera, aplicando así el Principio de Menor Sorpresa.
